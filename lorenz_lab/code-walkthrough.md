Основной маршрут выполнения:

```text
python main.py
  → load_config: JSON → словарь c с проверками
  → run_experiments:
       rhs + integrate → Эйлер / RK4
       rhs + solve_ivp → RK45 / DOP853

       запись CSV / NPZ / summary.json

  → render_animation: две траектории → GIF, если не задан skip-animation

```

Каждый модуль можно импортировать без полного запуска экспериментов. Строки `if __name__ == '__main__'` отделяют прямой запуск от импорта. Исключение — определения, импорты и настройки уровня модуля выполняются при импорте: например, создание стандартных Parameters и выбор backend в visualization.py.

## Формы массивов: где чаще всего спрашивают

При основном запуске M=4001, d=3. В универсальных тестах integrate допускает и d=1.

| Объект | Форма | Содержание |
| --- | --- | --- |
| `u`, `u0`, `k1..k4`, `rhs(...)` | `(3,)` | Один вектор состояния или скорости; различать их смысл |
| `t`, `grid` | `(M,)` | Общие моменты выдачи |
| `Solution.y`, `values`, `ref`, `perturbed` | `(M,3)` | Время по строкам, компоненты по столбцам |
| `sol.y` от SciPy без t_eval | `(3,K)` | Компоненты по строкам, внутренние моменты по столбцам |
| `sol.sol(grid)` | `(3,M)` | Оценка адаптивного решения на запрошенной сетке |
| `sol.sol(grid).T` | `(M,3)` | Та же оценка после перестановки двух осей |
| `J` | `(3,3)` | Матрица частных производных в одной точке |
| `error`, `distance`, `mask` | `(M,)` | Одно число/булево значение на момент времени |
| `fine.y`, `fine_p.y` | `(8001,3)` | Вдвое больше шагов при h/2 |
| `eigen` | `(3,)`, возможно complex | Три собственных значения одного Якобиана |

`.T` здесь транспонирует двумерный массив; у одномерного вектора `(3,)` его форма от `.T` не изменится. `axis=1` у norm для `(M,3)` сворачивает **координаты внутри каждой строки** и выдаёт M расстояний. `axis=0` у min/max сворачивает **время** и оставляет три координатных экстремума. Без axis норма всего массива означала бы другую метрику.

Пример на трёх строках:

```python
A = np.array([[3., 4., 0.], [0., 0., 2.], [1., 2., 2.]])
np.linalg.norm(A, axis=1)  # [5., 2., 3.]
A[:, 0]                  # [3., 0., 1.]: первая компонента всех состояний
A[-1]                    # [1., 2., 2.]: последнее состояние
A[A[:, 0] > 0]           # первая и третья строки
```

Булева маска выбирает строки, но не создаёт новую временную сетку автоматически: данные и соответствующие времена нужно выбирать **той же маской**. Например, `grid[mask]` и `distance[mask]` имеют одинаковую длину. Перенос маски длины 4001 на fine.t длины 8001 некорректен; поэтому для fine создаётся новая fm.

## Один настоящий шаг: подстановка чисел

Следующие числа вычислены вызовами **текущих** rhs/euler_step/rk4_step, а не переписаны из чужого примера. Полные значения сохранены в [examples.json](code-walkthrough/examples.json). Начало u=[1;1;1], t=0, h=0,01. Точки с запятой разделяют компоненты; десятичный разделитель ниже — точка.

### Эйлер

1. `rhs(0,u)` даёт скорость [0;26;−1.66666666667].
2. `h*rhs(...)` — изменение [0;0.26;−0.0166666666667].
3. Прибавление к u даёт следующий вектор:

`[1; 1.26; 0.983333333333]`

Не нужно выполнять rhs отдельно для x, затем для уже изменённого y: все компоненты одного шага должны использовать одно исходное состояние. Наш векторный код это обеспечивает.

### RK4: состояния и скорости — разные вещи

| Этап | Промежуточное состояние | Скорость |
| --- | --- | --- |
| 1 | `[1; 1; 1]` | `[0; 26; -1.66666666667]` |
| 2 | `[1; 1.13; 0.991666666667]` | `[1.3; 25.8783333333; -1.51444444444]` |
| 3 | `[1.0065; 1.12939166667; 0.992427777778]` | `[1.22891666667; 26.053729775; -1.50974136157]` |
| 4 | `[1.01228916667; 1.26053729775; 0.984902586384]` | `[2.48248131083; 26.0865531505; -1.35037864633]` |

Взвешенная средняя скорость `(k1+2*k2+2*k3+k4)/6`:

`[1.25671910736; 25.9917798945; -1.51090282084]`

Итог `u+h*weighted_derivative`:

`[1.01256719107; 1.25991779895; 0.984890971792]`

Видно, что стадии — не готовые следующие координаты. h входит в промежуточные состояния и окончательное обновление, но kᵢ определены как скорости. Поэтому нельзя ещё раз умножить kᵢ на h при сохранении прежней окончательной формулы.

## Один цикл integrate на короткой сетке

Для проверки формы достаточно мысленно заменить основной интервал на [0,0.02], h=.01:

```text
t = [0.00, 0.01, 0.02]       # 3 точки, 2 шага
y = empty((3,3))
y[0] = [1,1,1]
i=0 → y[1] = step(fun, t[0], y[0], h)
i=1 → y[2] = step(fun, t[1], y[1], h)
N = len(t)-1 = 2
nfev = 2 для Эйлера или 8 для RK4
```

Незаполненная строка empty не читается: y[i] уже записана прежде, чем нужно вычислить y[i+1]. При переполнении функция прекращается и не возвращает частичный массив как успешное решение.

## Что можно и нельзя менять во время демонстрации

- Менять параметры исследования следует в config.json, а не внутри формулы RK4. Для стандартного файла все размерности и границы согласованы.
- Значения `2`, `6` и весов в RK4 относятся к математической таблице метода. Формат графика и число кадров — к визуализации. Их смысл подробно разделён в паспорте чисел.
- `load_config` выполняет базовые проверки, но не является универсальной схемой валидации всех возможных JSON. Например, не проверяет отдельным условием целочисленность repeats или сохранение u0+delta после округления.
- Если изменить окно или возмущение так, что положительных расстояний внутри окна меньше двух, основной np.polyfit не сможет дать корректный наклон. Дополнительная функция slope_result умеет возвращать None, но это не означает, что основной эксперимент автоматически защищён от любого такого ввода.
- `write_csv` ожидает непустой список строк. Готовая постановка его обеспечивает; произвольные пустые наборы альтернатив потребовали бы дополнительной проверки.
- После изменения кода номера строк могут сдвинуться. [manifest.json](code-walkthrough/manifest.json) хранит SHA256 и количество строк исходников этой версии: расхождение хеша означает, что построчный разбор нужно сверить заново.

## Как отвечать по любой строке на защите

Назвать **вход → тип и форму → операцию → результат → назначение**. Например:

> «values и ref имеют форму (4001,3). Вычитание даёт три ошибки на каждый момент. norm с axis=1 превращает каждую тройку в евклидово расстояние; получается массив из 4001 числа. Его максимум используется как максимальная ошибка на общей выходной сетке относительно численного эталона».

Начните с numerical_methods.py и lorenz.py, затем переходите к experiments.py. Длинные строки визуализации и генерации Markdown можно разбирать как несколько независимых действий, разделённых `;`. Не нужно приписывать рисованию графика влияние на численную точность.
