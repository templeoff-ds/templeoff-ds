# Постановка лабораторной работы

**Тема:** численное исследование системы Лоренца, сравнение интеграторов и чувствительности к начальным условиям.

Решить x'=σ(y−x), y'=x(ρ−z)−y, z'=xy−βz при σ=10, ρ=28, β=8/3. Начальное состояние (1,1,1), для чувствительности — (1+10⁻⁸,1,1). Основной интервал [0,40], постоянный шаг 0,01. Параметры вынесены в config.json.

1. Самостоятельно реализовать Эйлер и классический RK4. Использовать SciPy RK45 как библиотечное сравнение и высокоточный численный эталон, не аналитическое решение.
2. Построить аттрактор, x(t),y(t),z(t) и фазовые проекции, сохранив рисунки не ниже 150 dpi.
3. Сравнить методы на общей выходной сетке: векторные ошибки, максимум, конечную ошибку, время, шаги и вызовы f. Отдельно выделить короткий интервал [0,2].
4. Исследовать шаги 0,04; 0,02; 0,01; 0,005; 0,0025 на [0,2]. Не скрывать неустойчивость или отклонение порядка. При необходимости добавить отдельную серию меньших шагов.
5. Показать расхождение близких траекторий, расстояние и ln расстояния. Оценить рост в фиксированном окне и повторить с h/2. Не объявлять наклон точным показателем Ляпунова.
6. Аналитически найти равновесия, вывести Якобиан и исследовать его спектр. Отличать локальную устойчивость состояния от численной устойчивости метода.
7. Создать GIF двух траекторий, работающий без GUI.
8. Подготовить подробную теорию, отчёт по реальным данным и план защиты с вопросами и ответами; предоставить Notebook и тесты.

Методические уточнения: RK45 проверяется на коротком интервале более строгим RK45 и DOP853. Долгосрочные ошибки относительно численного эталона не используются для ранжирования точности методов. Переполнение крупного шага Эйлера регистрируется как неудачный расчёт, а не заменяется искусственным конечным значением. Основные эксперименты не скрывают переходный процесс; его исключают только из части рисунков.

Проверка: python -m unittest discover -s tests -v. Полный запуск: python main.py. Критерий готовности — реальное выполнение всех этапов и наличие артефактов; изучение примера одногруппника отложено по указанию пользователя.
