# Построчный индекс числовых литералов

Каждое исполняемое числовое вхождение в файлах .py приведено отдельно. Одинаковые значения в разных контекстах могут иметь разный смысл. Номер строки соответствует версии кода, с которой собран индекс. Отрицательный литерал в AST состоит из знака операции и положительного числа: контекст строки сохраняет знак. Числа внутри строковых подписей, цветов, спецификаторов формата, имён файлов и документации не являются числовыми AST-узлами; они объяснены в §9 [основного разбора](constants-explained.md).
