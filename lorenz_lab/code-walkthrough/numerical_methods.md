# Построчный разбор numerical_methods.py

Самостоятельные методы. Самый важный файл для объяснения собственного численного алгоритма.

[Исходный файл](../numerical_methods.py) · [Общий маршрут чтения](../code-walkthrough.md)

Каждая физическая строка приведена отдельно. Если несколько действий соединены `;`, они выполняются слева направо. Длинная строка может переноситься экраном, но номер относится к исходному файлу.

## Интерфейсы функций

- **euler_step**, строка 12: один явный шаг: fun(t,u) — скорость, u — вектор, h — положительный скаляр; возвращается новый вектор.
- **rk4_step**, строка 15: один классический четырёхстадийный шаг, интерфейс такой же, как у Эйлера.
- **time_grid**, строка 23: проверка границ/шага и построение одномерной сетки, включающей оба конца.
- **integrate**, строка 32: многократный вызов выбранной формулы шага; возвращает Solution, а не только последнюю точку.
