# Построчный разбор experiments.py

Все пять исследований: сравнение, сходимость, чувствительность и спектры; различие внутренней/выходной сеток.

[Исходный файл](../experiments.py) · [Общий маршрут чтения](../code-walkthrough.md)

Каждая физическая строка приведена отдельно. Если несколько действий соединены `;`, они выполняются слева направо. Длинная строка может переноситься экраном, но номер относится к исходному файлу.

## Интерфейсы функций

- **load_config**, строка 15: чтение JSON и проверки принятой структуры; результат словарь c.
- **adaptive**, строка 38: обёртка SciPy solve_ivp; возвращает объект с внутренними шагами и непрерывной интерполяцией.
- **timed**, строка 45: повторный вызов функции call без аргументов и медианное время её выполнения.
- **write_csv**, строка 51: запись непустого списка словарей rows в таблицу path.
- **run_experiments**, строка 55: все основные численные расчёты по c и запись их данных в output.
- **call**, строка 64: локальный повторяемый запуск RK45 с последующей оценкой на общей сетке.
