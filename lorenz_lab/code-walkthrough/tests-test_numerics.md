## Интерфейсы функций

- **test_rhs_known_value**, строка 9: проверка правой части по вручную вычисленному вектору.

- **test_rk4_exponential**, строка 15: проверка RK4 на точном exp(t).
- **test_rk4_nonautonomous**, строка 19: проверка временных аргументов стадий на u′=tu.
- **test_rk4_order**, строка 24: измерение четвёртого порядка на точной задаче.
- **test_euler_order**, строка 28: измерение первого порядка на точной задаче.
- **test_short_agreement**, строка 32: сравнение короткого Лоренца с независимым DOP853.
- **test_equilibria_and_spectra**, строка 38: проверка количества/остатков равновесий и знака спектра.
- **test_jacobian_independent_difference**, строка 45: независимая разностная проверка аналитического Якобиана.
- **test_grid_and_evaluation_counts**, строка 50: проверка сетки, реальных вызовов и недопустимых входов.
- **test_standard_trajectories_finite**, строка 60: проверка конечности полных стандартных траекторий.
- **test_overflow_not_silent**, строка 66: проверка явного отказа при искусственном переполнении.
