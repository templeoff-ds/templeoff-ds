# Построчный разбор build_constant_index.py

Служебная генерация индекса констант и таблиц; это не интегратор.

[Исходный файл](../build_constant_index.py) · [Общий маршрут чтения](../code-walkthrough.md)

Каждая физическая строка приведена отдельно. Если несколько действий соединены `;`, они выполняются слева направо. Длинная строка может переноситься экраном, но номер относится к исходному файлу.

## Интерфейсы функций

- **generate**, строка 53: создание индекса констант и Markdown-таблиц из уже рассчитанного JSON.
- **__init__**, строка 44: инициализация служебного посетителя дерева Python.
- **visit_FunctionDef**, строка 46: обработка узла определения функции при обходе AST.
- **visit_Constant**, строка 49: обработка литерала при обходе AST, без выполнения кода.
- **value**, строка 88: форматирование отдельного поля сравнительной таблицы.
