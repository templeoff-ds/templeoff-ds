# Построчный разбор main.py

С чего начинается запуск: CLI, порядок этапов и выходная папка.

[Исходный файл](../main.py) · [Общий маршрут чтения](../code-walkthrough.md)

Каждая физическая строка приведена отдельно. Если несколько действий соединены `;`, они выполняются слева направо. Длинная строка может переноситься экраном, но номер относится к исходному файлу.

## Интерфейсы функций

- **main**, строка 10: точка входа CLI, последовательно связывающая конфигурацию, расчёты, рисунки и отчёт.
