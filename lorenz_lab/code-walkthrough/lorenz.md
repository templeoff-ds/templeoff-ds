# Построчный разбор lorenz.py

Математическая модель: функция скоростей, матрица производных и равновесия.

[Исходный файл](../lorenz.py) · [Общий маршрут чтения](../code-walkthrough.md)

Каждая физическая строка приведена отдельно. Если несколько действий соединены `;`, они выполняются слева направо. Длинная строка может переноситься экраном, но номер относится к исходному файлу.

## Интерфейсы функций

- **rhs**, строка 17: скорость в точке: t — скаляр, state — вектор (3,), params — Parameters; результат (3,).
- **jacobian**, строка 23: матрица производных в заданном state: вход (3,), выход (3,3).
- **equilibria**, строка 29: аналитические точки для params; результат словарь имён и векторов (3,).
- **__post_init__**, строка 11: автоматическая проверка только что созданных параметров перед использованием модели.
