# Построчный разбор visualization.py

Как готовые массивы становятся графиками и GIF без изменения расчёта.

[Исходный файл](../visualization.py) · [Общий маршрут чтения](../code-walkthrough.md)

Каждая физическая строка приведена отдельно. Если несколько действий соединены `;`, они выполняются слева направо. Длинная строка может переноситься экраном, но номер относится к исходному файлу.

## Интерфейсы функций

- **setup_style**, строка 11: настройки оформления, не изменение математической модели.
- **render_figures**, строка 16: построение PNG из data по конфигурации c в папку output.
- **render_animation**, строка 70: создание GIF по уже рассчитанным двум траекториям.
- **save**, строка 20: локальный помощник сохранения одной фигуры или таблицы; использует путь из внешней функции.
- **update**, строка 82: обновление графических объектов до заданного конца end одного кадра; функция не интегрирует ОДУ.
