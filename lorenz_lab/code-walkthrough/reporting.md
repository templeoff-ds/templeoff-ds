# Построчный разбор reporting.py

Как реальные метрики и ссылки попадают в отчёт.

[Исходный файл](../reporting.py) · [Общий маршрут чтения](../code-walkthrough.md)

Каждая физическая строка приведена отдельно. Если несколько действий соединены `;`, они выполняются слева направо. Длинная строка может переноситься экраном, но номер относится к исходному файлу.

## Интерфейсы функций

- **number**, строка 6: читаемое форматирование числа или отсутствующего результата для отчёта.
- **build_report**, строка 9: сборка шаблона и реальных результатов в Markdown с относительными ссылками.
- **make**, строка 41: вложенная сборка отчёта относительно конкретной папки base.
